# DriveFix

Учебный адаптивный сайт автосервиса, перенесённый из макета Figma.

## Файлы

- `index.html` — структура восьми разделов страницы.
- `style.css` — дизайн, адаптивная версия и анимации.
- `script.js` — мобильное меню, проверка формы и сообщение об отправке.
- `assets/car.png` — иллюстрация автомобиля из макета.

## Как запустить в VS Code

1. Распакуйте архив и откройте папку `drivefix` в VS Code.
2. Установите расширение **Live Server**, если оно ещё не установлено.
3. Откройте `index.html`.
4. Нажмите правой кнопкой мыши внутри файла и выберите **Open with Live Server**.

Можно также дважды нажать на `index.html`: страница работает без сборщика и дополнительных библиотек.

## Что работает

- навигация по разделам;
- адаптивное мобильное меню;
- онлайн-форма с обязательными полями;
- проверка выбранной даты;
- сообщение об успешной отправке;
- анимация появления блоков при прокрутке.

Форма демонстрационная: заявка отображается в браузере и не отправляется на сервер.
